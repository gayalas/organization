STEP 4 — Configure DB1 for replication
4.1 Open DB1's postgresql.conf
Run:
notepad "C:\Program Files\PostgreSQL\17\data\postgresql.conf"
Find:
#wal_level = replica
Change it to:
wal_level = replica
Then find:
#max_wal_senders = 10
Change it to:
max_wal_senders = 10
Save the file.
Why these settings?
wal_level = replica tells PostgreSQL to generate the WAL information needed for replication.
max_wal_senders = 10 allows DB1 to have replication connections sending WAL to standby servers.





4.2 Configure DB1's pg_hba.conf
Open:
notepad "C:\Program Files\PostgreSQL\17\data\pg_hba.conf"
Go to the bottom of the file and add:
host    replication    replicator    127.0.0.1/32    scram-sha-256
This means:
DB1
 │
 │ user = replicator
 │ database = replication
 │ localhost
 ▼
DB2

Paso 5 — Preparar DB2 para recibir la copia de DB1
Ahora vamos a eliminar el contenido actual de:

Esto no afecta DB1. Solamente estamos eliminando la instancia independiente que creamos anteriormente, porque pg_basebackup va a reemplazarla por una copia física de DB1.
Ejecuta:
